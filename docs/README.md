## 实现与卸载说明

- **展开与持久化边界**：DSH 未公开设置右侧栏呈现形态的 API，
  插件在收起态预置全屏呈现并读取/驱动 `ctx.sidebarRight.adopted` 与 store 的 `setMode('fullscreen')`；
  如未来版本更改这些内部结构，插件会安全失效并在控制台记录一次警告。
  按会话保存的呈现形态写入 `localStorage`（`dsh.sidebar-right.v1.<sessionId>`）；
  启用期间记录为全屏的会话在停用插件后仍保持全屏，直到手动用面板控件切回分屏并收起保存。
- **焦点落点与超时**：打开提交后先聚焦活动停靠分栏，再依次寻找嵌入 frame、编辑器、
  内容根节点或滚动查看器（无 `tabindex` 时临时添加 `tabindex="-1"` 与 `data-dsh-aggressive-sidebar-focus`）；
  页面获焦、面板关闭/切换会话、指针或按键输入、窗口失焦或 800 ms 后停止补试，且绝不抢占页面已有焦点。
- **卸载清理**：停用插件会移除设置面板、样式表、监听器与临时 `tabindex` 标记，并还原 store 映射。

## 验证说明

`node --test` 使用伪造的控制器、store 与页面验证全屏预置、中途切回分屏尊重、store 替换、
缺失内部结构时安全失效、各类焦点落点优先顺序、800 ms/交互取消与卸载还原。

浏览器验证在一次性配置中进行。打开插件详情页，切换展开模式并刷新确认选择已保存。
宽屏下检查全屏和左边栏边缘两种落点。
在「展开到左边栏」模式中，收起、打开或拖动左边栏时，右侧栏应始终贴合左栏边缘。
同时检查原生分屏按钮和键盘焦点。窄屏下检查原生全屏和详情页宽度。
停用插件后，测试新会话是否回到原生分屏。

构建后可用逐帧回归测试验证收展动画和减少动态效果。
用 [dsh-web-drive](../../../tools/dsh-web-drive/README.md) 准备刚安装插件的一次性英文 profile，将其登录 URL 传给测试。
测试从默认的「展开到左边栏」开始。

```sh
DSH_SIDEBAR_TEST_URL="$test_profile_url" node --test test/sidebar-motion.test.mts
```
